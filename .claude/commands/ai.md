방금 올린 평가지의 서술형을 다시 씁니다. 아래를 **순서대로 끝까지** 하십시오.
사용자에게 중간 확인을 묻지 마십시오 — 이 명령 자체가 실행 승인입니다.

## 1. 내보내기

```
py -3.10 ai_bridge.py export
```

`$ARGUMENTS` 가 숫자면 그 업로드 번호를 붙입니다 (`export 12`).
비어 있으면 가장 최근 업로드가 대상입니다.

"다시 만들 것이 없습니다" 가 나오면 이미 AI 문장이 들어가 있다는 뜻입니다.
그대로 사용자에게 알리고 멈추십시오.

## 2. 작성

`handoff_ai/요청.md` 를 읽고, 각 작업의 지시문을 그대로 따라 문장을 만드십시오.
지시문에 적힌 규칙(공통 주제 우선, 사건·말투 제거, 제언체)이 곧 품질 기준입니다.
읽을 때 규칙 설명은 작업마다 같으므로, 재료(원문 응답 목록)에 집중하십시오.

결과를 `handoff_ai/응답.json` 에 씁니다.

```json
[{"id": 1243, "text": "첫 줄\n둘째 줄",
  "evidence": [{"quote": "원문 그대로", "why": "근거"}]}]
```

- 작업 번호(`id`)를 반드시 요청서의 것과 맞추십시오. 이전 실행의 번호를 재사용하면 안 됩니다.
- **근거가 없으면 그 작업을 빼십시오.** 지어내는 것보다 비는 편이 낫습니다.
- 한 사람만 말한 내용은 싣지 않습니다 — 그 사람이 특정됩니다.

## 3. 반영

```
py -3.10 ai_bridge.py import
```

## 4. 보고

사용자에게 이렇게만 알리십시오.

- 몇 건이 반영됐고 리포트 몇 장이 다시 만들어졌는지
- 대표 문장 한두 개 (전/후 대비가 있으면 함께)
- 근거가 없어 뺀 항목이 있으면 무엇을 왜 뺐는지
- 마지막에 "브라우저를 새로고침하십시오"

작업 내역을 길게 늘어놓지 마십시오.
