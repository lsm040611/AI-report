# 인터넷에 올리기 (Render)

내 컴퓨터에서만 돌던 서버를 인터넷 주소로 만들어, 팀원이 링크만 열면
쓸 수 있게 하는 방법입니다. 카드 등록 없이 무료로 됩니다.

**걸리는 시간 20~30분.** 처음 한 번만 하면 되고, 그 뒤로는 깃에 푸시할 때마다
알아서 다시 올라갑니다.

## 1단계 — 렌더 가입

1. 크롬에서 <https://render.com> 접속
2. 오른쪽 위 **Get Started** → **GitHub** 로 가입
3. 깃허브 로그인 → **Authorize Render** 누르기

> 깃허브 계정은 이미 있습니다(`lsm040611`). 그 계정으로 로그인하시면 됩니다.

## 2단계 — 저장소 연결 권한 주기

1. 가입하면 저장소를 고르라고 나옵니다. 안 나오면 왼쪽 위 프로필 →
   **Account Settings** → **GitHub** → **Configure**
2. **Only select repositories** 를 고르고 **AI-report** 만 체크
3. **Save**

## 3단계 — 서비스 만들기

1. 대시보드 오른쪽 위 **New +** → **Blueprint**
2. 목록에서 **AI-report** 선택 → **Connect**
3. 렌더가 저장소의 `render.yaml` 을 읽고 만들 서비스를 보여 줍니다
4. 아래에 **비밀 값을 넣으라는 칸**이 나옵니다. 여기가 제일 중요합니다.

| 칸 이름 | 넣을 값 |
|---|---|
| `HR_AUTH_PASS` | **팀원과 공유할 비밀번호를 직접 정해서 입력** |
| `ANTHROPIC_API_KEY` | `api.env` 파일에 있는 `sk-ant-...` 를 복사해서 붙여넣기 |
| `HR_SMTP_HOST` | 메일 안 쓸 거면 비워 두기 |
| `HR_SMTP_PORT` | 비워 두기 |
| `HR_SMTP_USER` | 비워 두기 |
| `HR_SMTP_PASS` | 비워 두기 |

5. **Apply** 누르기

## 4단계 — 무료 요금제에 맞게 두 칸만 고치기

`render.yaml` 은 저장 공간이 있는 걸 전제로 써 두었습니다. 무료라면 두 칸을
바꿔야 서버가 뜹니다.

1. 만들어진 서비스 클릭 → 왼쪽 **Environment**
2. 아래 두 개를 찾아 값을 고치고 **Save Changes**

| 이름 | 무료일 때 넣을 값 |
|---|---|
| `HR_STORAGE` | `./storage` |
| `HR_DB_URL` | `sqlite:///./hr_report.db` |

## 5단계 — 기다렸다가 열어 보기

1. **Logs** 탭에서 초록색 **Live** 가 뜰 때까지 기다립니다 (3~5분)
2. 맨 위에 `https://hr-report-engine-xxxx.onrender.com` 주소가 생깁니다
3. 그 주소를 클릭
4. 브라우저가 아이디·비밀번호를 물어봅니다

| | |
|---|---|
| 아이디 | `hrd` |
| 비밀번호 | 3단계에서 정하신 것 |

들어가지면 끝입니다.

## 잘 안 될 때

**주소를 열었더니 하얗고 안 넘어감**
서버가 자고 있습니다. 50초 기다려 보세요. 3분이 지나도 그대로면 Logs 를 보세요.

**"비밀번호가 설정되지 않아 바깥에서는 열 수 없습니다"**
`HR_AUTH_PASS` 가 안 들어갔습니다. Environment 탭에서 넣고 Save 하면
서버가 자동으로 다시 뜹니다.

**Logs 에 빨간 글씨로 `ModuleNotFoundError`**
`requirements.txt` 에 없는 라이브러리를 쓰고 있습니다. 그 줄을 저에게 보여
주세요.

**Logs 에 `Address already in use` 또는 포트 오류**
`startCommand` 에서 `--port $PORT` 를 지우면 이렇게 됩니다. 포트는 렌더가
정해 줍니다. `render.yaml` 을 원래대로 두세요.

**리포트를 만들려는데 목(mock) 문장만 나옴**
`ANTHROPIC_API_KEY` 가 안 들어갔습니다. `/health` 를 열어 `"generation"` 이
`"mock"` 이면 그렇습니다. Environment 에서 넣어 주세요.

**메일이 안 감**
`HR_MAIL_ENABLED` 를 `1` 로 바꾸고, `mail.env` 에 있는 네 개를 Environment 에
그대로 넣으세요.

## 나중에 제대로 운용하게 되면

무료의 두 가지 제약(자료 사라짐 · 잠듦)은 요금제를 올리면 없어집니다.

1. 서비스 → **Settings** → **Instance Type** 을 Starter 로 변경
2. `render.yaml` 맨 아래 `disk:` 세 줄의 주석(`#`)을 지우고 푸시
3. `HR_STORAGE` 를 `/var/data/storage`, `HR_DB_URL` 을
   `sqlite:////var/data/hr_report.db` 로 되돌리기 (슬래시 4개 맞습니다)

여러 사람이 동시에 쓰게 되면 SQLite 대신 PostgreSQL 로 바꾸는 게 좋습니다.
렌더에서 DB 를 만들어 붙이면 `DATABASE_URL` 이 자동으로 꽂히고, 코드는
그걸 알아서 읽습니다 — **고칠 것 없습니다.**
